# Datos de Avisador Radar

Límites de velocidad de las vías de España, generados cada mes a partir de OpenStreetMap por
[avisador-radar](https://github.com/gavilanfranc/avisador-radar) (GitHub Actions). Se publican en
**Releases**: `espana-limites.bin` (formato propio de la app) y `manifest.json` (fecha, tamaño y
SHA-256). Se conservan las 2 últimas publicaciones.

van marcados como aproximados. Solo orientativo: mandan siempre las señales.
